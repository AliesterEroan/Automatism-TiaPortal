## 🛠️ Tech Stack

- **Platform**: Siemens TIA Portal
- **Hardware**: Siemens PLCs (S7-1200, S7-1500)
- **Languages**: 
  - Ladder Logic (LAD)
  - Function Block Diagram (FBD)
  - Structured Text (ST)
- **Integration**:
  - MQTT for IoT communication
  - PHP for web interfaces
  - Python for backend services
  - SQLite for data storage

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/AliesterEroan/Automatism-TiaPortal.git
   ```

2. **Install TIA Portal**
   - Install Siemens TIA Portal software
   - Configure licensing
   - Set up project environment

3. **Open a Project**
   - Launch TIA Portal
   - Open any .ap18 project file
   - Review hardware configuration

4. **Configure Hardware**
   - Set up PLC hardware
   - Configure network interfaces
   - Add I/O modules

5. **Deploy and Test**
   - Compile project
   - Download to PLC
   - Monitor operation
